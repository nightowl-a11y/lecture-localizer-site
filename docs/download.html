강의 현지화 도구 내려받기

교수님 강의 영상을 영어로 바꿔 주는 도구(1안)와, 영어 교안 도구(2안)를 한 묶음으로 내려받습니다.

배포 준비 중 · 버전 번호: 11/18 확정 예정

버전과 배포 구성은 11월 18일 확정 예정입니다. 먼저 PC 준비 조건을 확인해 주세요.

설치 전 확인하기 도구 내려받기 설치 순서 보기

PC 조건 (현재 안내 기준, 변경 가능)
Windows 10/11 64비트 · RAM 16GB 이상 · 여유 공간 100GB 이상
필요한 Adobe 프로그램 확인

이 묶음에는 무엇이 들어 있나요?

1안과 2안이 같은 묶음입니다. START_AIEN.bat 시작 화면에서 쓸 도구를 고르면 됩니다.

1안 · 영상 영문화

한국어 강의 영상에서 자막·화면 글자·음성을 영어로 바꿔
영상을 만듭니다.

2안 · 영어 교안

영어 교안 화면으로 영어 강의 영상을 만듭니다.
아바타는 아직 연결 전이라,
시작 점검 화면에서 '아바타 넣기'를 끄고 교안만으로 만듭니다.

설치 파일

압축을 풀면 시작 파일 2개가 보입니다.
처음_한번_설치.bat과 START_AIEN.bat입니다.
자세한 설명은 안내 페이지에서 볼 수 있습니다.

이미 설치하셨다면: 업데이트

이미 설치한 분만 쓰는 작은 파일입니다(약 18.5MB). 처음 설치하는 분은 위의 전체 묶음을 내려받아 주세요.

업데이트 파일 내려받기
  1. 1

    도구 끄기

    켜져 있는 도구(작은 검은 창 포함)를 모두 닫습니다.

  2. 2

    압축 풀기

    내려받은 업데이트 zip을 아무 곳에나 풉니다.

  3. 3

    업데이트.bat 실행

    더블클릭한 뒤 화면 안내에 따라 도구 폴더를 찾아 Y를 입력합니다.

디스크 여유 공간이 약 2GB 필요합니다. API 키(.env)와 과정 설정은 그대로 유지됩니다.
업데이트 뒤 문제가 있으면 도구 폴더의 되돌리기.bat으로 이전 버전으로 돌아갈 수 있습니다. 설치된 Python 구성이 다르면 업데이트가 멈추고 담당자에게 전체 업데이트 zip을 받으라고 안내합니다.

현재 버전은 1안 도구 화면 맨 아래의 '버전 · 포터블' 표시에서 확인합니다.

꼭 알아 두세요

API 키와 접속 코드는 이 사이트와 내려받는 파일에 들어 있지 않습니다. 따로 전달받아 도구 화면의 입력 창에 넣습니다.
Adobe(Photoshop·After Effects·Premiere)가 PC에 설치되어 있어야 합니다. 동시에 로그인할 수 있는 PC는 2대까지입니다.
