설치 방법 안내

내 PC에 도구를 설치하는 순서와, 막혔을 때 스스로 해결하는 방법을 모았습니다.

배포 준비 중 · 버전 번호: 11/18 확정 예정

현재는 사전 안내이며, 최종 구성은 확정 후 갱신됩니다.

설치 전 확인하기 도구 내려받기

준비 조건 설치 순서 파일 설명 자주 묻는 질문 스스로 해결 문의

1. 시작하기 전에 확인할 것

설치 전에 확인할 PC 조건입니다. 최종 검증 전의 안내 기준이라 바뀔 수 있습니다.

API 키는 따로 전달해 드립니다. 이 사이트에는 없고, 설치 뒤 도구의 입력 창에 넣습니다.

그 밖에 막히는 일은 아래 설치 순서와 자주 묻는 질문에서 필요할 때 안내합니다.

2. 설치 순서

위에서 아래로 차례대로 따라 해 주세요. 단계 이름과 화면 그림은 설치 스크립트가 확정된 뒤 채웁니다.

설치 단계는 11/18 이후 확정됩니다. 지금은 예정 틀입니다.
  1. 1

    내려받기

    위의 [도구 내려받기] 버튼을 누릅니다.

  2. 2

    압축 풀기

    아무 곳에나 풀어도 됩니다.

    다만 설치 파일이 D: 드라이브에 폴더를 만들기 때문에, D: 드라이브가 있는 PC여야 합니다.

  3. 3

    bat 차단 해제

    파일 속성에서 '차단 해제'를 체크합니다.

    막혔나요? → bat 파일이 열리지 않아요

  4. 4

    처음_한번_설치.bat 실행

    처음 한 번만 더블클릭합니다.

  5. 5

    도구 켜기

    START_AIEN.bat(바로 가기 하나)을 더블클릭하고, 뜨는 창에서 1안 또는 2안 버튼을 고릅니다. 고른 도구가 켜지고 창은 닫힙니다. 도구 창은 한 PC에 하나만 켭니다.

    2안은 아바타가 아직 연결 전이라, 2안 시작 점검 화면에서 '아바타 넣기'를 끄고 교안만으로 만듭니다(차시마다 설정).

  6. 6

    키 입력

    도구 오른쪽 위의 '필요한 정보' 버튼을 눌러 따로 전달받은 키를 넣습니다. 키는 이 PC에만 저장되고, 화면에는 끝 4자리만 보입니다.

    비어 있는 필수 키는 '시작 점검'에서 경고로 알려 줍니다.

    막혔나요? → 키 입력 창에 넣어도 안 돼요

  7. 7

    작은 시험

    한 장면으로 잘 되는지 확인합니다.

각 단계마다 "이렇게 보이면 성공" 한 줄과 화면 그림을 넣을 예정입니다. 2안은 필요한 키가 더 많아, 도구 화면의 '필요한 정보' 목록을 따라 입력합니다.

3. 파일별 설명

압축을 풀면 첫 화면에 아래 5개만 보입니다. 나머지는 모두 program 폴더 안에 있습니다.

START_AIEN.bat

도구를 켭니다. 더블클릭하면 시작 화면이 뜨고, "1안 · 영어 음성·자막·입모양" 또는 "2안 · 영문 슬라이드 + 아바타" 중 고르면 그 도구가 켜집니다. 2안은 시작 점검 화면에서 '아바타 넣기'를 끄면 아바타 없이 교안만으로 영상을 만들 수 있습니다.

처음_한번_설치.bat

도구를 쓰기 전에 처음 한 번만 실행하는 설치 파일입니다.

되돌리기.bat

업데이트한 뒤 새 버전에 문제가 있을 때만 씁니다. 도구를 끄고 더블클릭하면 이전 버전으로 바꿔 줍니다. 한 번 더 누르면 다시 새 버전으로 돌아옵니다. 지우는 것은 없고, 과정 설정과 결과 파일은 그대로입니다. 설치 직후에는 돌아갈 이전 버전이 없어서 아무것도 바뀌지 않습니다. 안내 문구는 영어로 나옵니다.

읽어보세요.txt

설치 순서와 이 안내 사이트 주소를 짧게 적은 파일입니다.

program 폴더

도구가 돌아가는 파일이 모두 들어 있습니다. 열어서 고치거나 지우지 마세요.

원본(서버·NAS) 폴더는 읽기만 하고, 작업 폴더는 원본 폴더 밖에 둡니다. 키는 따로 전달해 드리며, 도구 화면의 입력 창에서만 넣습니다.

4. 자주 묻는 질문

눌러서 펼쳐 보세요.

bat 파일이 열리지 않아요 / 백신이 막아요

파일 속성에서 '차단 해제'를 체크해 보세요. 그래도 안 되면 전산에 AhnLab 예외 등록을 요청해 주세요. 메일·웹으로 받은 파일이 막히면 공유 폴더로 복사해 받는 방법도 있습니다.

Adobe가 로그아웃됐어요

동시 로그인은 2대까지입니다. 다른 PC에서 쓰는 중인지 확인한 뒤 사용해 주세요. 안내 창이 뜨면 번역·검수처럼 Adobe가 필요 없는 단계를 먼저 하시면 됩니다.

"이미 작업 중"이라고 떠요

다른 PC가 같은 차시를 열고 있다는 안내입니다. 화면 위에 띠가 뜨고 그 차시의 실행·저장 단추가 흐려져서, 실행과 저장은 할 수 없고 보기·폴더 열기·문제 신고만 할 수 있습니다. 그 PC가 창을 닫거나 3분 동안 신호가 없으면 저절로 풀립니다. 차시를 나눠 작업해 주세요. 같은 차시 폴더를 여러 PC가 함께 쓸 때만 나타나고, PC마다 따로 설치해 각자 폴더를 쓰면 뜨지 않습니다.

도구 창을 두 번 켜면 어떻게 되나요?

한 PC에는 창 하나만 켜 주세요. 서버가 둘 떠서 헷갈릴 수 있습니다.

키 입력 창에 넣어도 안 돼요

전달받은 키를 다시 확인해 주세요. 앞뒤에 공백이 들어가지 않았는지, 어떤 서비스(Claude · ElevenLabs · sync.so)용 키인지도 확인해 주세요. 키는 도구 오른쪽 위의 '필요한 정보' 버튼에서 넣고, 화면에는 끝 4자리만 보입니다. 비어 있는 필수 키는 '시작 점검'에서 경고로 알려 줍니다.

작업 중 멈췄어요 / 오류가 나요

기록을 열어 마지막 부분을 확인하고, 설치·사용 문의로 알려 주세요. 차시·단계·마지막 줄을 함께 보내 주시면 빨리 도와 드릴 수 있습니다. 기록·복사 버튼 구현 확인 예정

디스크가 부족해요

차시 하나에 약 20GB와 백업이 필요합니다. 끝난 차시는 확정본을 외장하드에 따로 백업한 뒤 사람이 정리해 주세요. 도구는 확정본과 비용이 든 백업을 자동으로 지우지 않습니다.

업데이트는 어떻게 하나요?

이미 설치한 분은 작은 업데이트 파일을 받아 적용합니다. 순서는 내려받기 쪽의 업데이트 안내에 있습니다. 문제가 있으면 되돌리기.bat으로 이전 버전으로 돌아갑니다.

Premiere·After Effects 버전이 달라요

자동 업데이트는 꺼 주세요. 도구 1.0.4는 설치된 Adobe 프로그램 중 가장 높은 연도(예: 2027)를 자동으로 찾도록 바꾸었습니다. 실제 PC에서 되는지는 설치 실험으로 확인 중입니다. 확인된 버전은 실험 뒤 확정 예정

원본(서버)에 저장되나요?

아니요. 도구는 원본에 쓰지 않습니다. 작업 폴더를 원본 폴더 밖에 두어 주세요. 1안에서 작업 폴더를 원본 폴더 안으로 고르면 경고 창이 뜹니다.
